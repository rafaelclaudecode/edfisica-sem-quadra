# edfisica-sem-quadra
Página de vendas estática (pt-BR) do Kit "Educação Física Sem Quadra" — Método Carteira-Quadra.
- `index.html` — página de vendas (troque `CHECKOUT_URL_BASICO` e `CHECKOUT_URL_COMPLETO` pelo link do checkout; pixel Meta comentado no `<head>`)
- `obrigado.html` — página de obrigado (pixel Purchase comentado; troque `SUPORTE_EMAIL`)
- `privacidade.html` — privacidade e termos (troque `RESPONSAVEL_NOME`, `CNPJ_OU_CPF`, `SUPORTE_EMAIL`)
Sem build: publicar a pasta raiz (Cloudflare Pages, output dir `/`).
